# Virtual Tagging Engine — Interview Exercise

## Context

Cloud billing data is raw. Rows look like:

| date | service | account_id | region | usage_type | cost |
|------|---------|------------|--------|------------|------|
| 2024-01-01 | AmazonEC2 | 333333333333 | us-east-1 | BoxUsage:t3.medium | 45.50 |

Customers want to map their costs to internal teams (Infrastructure, Data, Backend, ...).
We call this mechanism a **virtual tag (vtag)**.

A vtag is a JSON object with ordered rules. **First matching rule wins.** If no rule matches, the row gets the default label.

See `src/vtags.js` for the full definition you'll be working with.
