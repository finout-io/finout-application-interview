# Virtual Tagging Engine — Interview Exercise

## Context

Cloud billing data is raw. Rows look like:

| date | service | account_id | region | usage_type | cost |
|------|---------|------------|--------|------------|------|
| 2024-01-01 | AmazonEC2 | 333333333333 | us-east-1 | BoxUsage:t3.medium | 45.50 |

Customers want to map their costs to internal teams (Infrastructure, Data, Backend, ...).
We call this mechanism a **virtual tag (vtag)**.

A vtag is a JSON object with ordered rules. **First matching rule wins.** If no rule matches, the row gets the default label.

See `src/vtags.js` for the full definition you'll be working with.

## Useful commands

The SQLite extension is pre-installed - in order to explorer the data

1. Command Palette (`Cmd/Ctrl+Shift+P`) → **SQLite: Open Database** → select
   `data/billing.db`. It shows up in the **SQLITE EXPLORER** panel in the sidebar,
   where you can browse the `billing` table's columns and rows directly.
2. To run your own query: right-click the connection in SQLITE EXPLORER (or Command
   Palette) → **SQLite: New Query** → type SQL, e.g. `SELECT DISTINCT service FROM
   billing;` → run it via the **Run Query** button/codelens that appears above what
   you typed.
